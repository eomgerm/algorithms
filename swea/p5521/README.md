## 문제 설명

<p class="txt">
							<strong>※SW Expert 아카데미의 문제를 무단 복제하는 것을&nbsp;금지합니다.</strong><br>
<br>
<br>
상원이의 생일 파티가 곧 열린다!<br>
<br>
그렇기에 상원이는 반 친구들에게 생일 파티 초대장을 주려고 한다.<br>
<br>
그러나 파티가 어색하게 되는 것을&nbsp;원치 않는 상원이는&nbsp;모든 친구들에게 초대장을&nbsp;줄 생각이&nbsp;없다.<br>
<br>
같은 반에 있지만, 서로 친한 친구가 아닐 수도 있기 때문이다.<br>
<br>
상원이는 우선 자신과 친한 친구들에게는 모두 초대장을 주기로 했다.<br>
<br>
여기에 더해서 친한 친구의 친한 친구인 경우에도 초대장을 주기로 했다.<br>
<br>
총 몇 명의 친구들에게 초대장을 주어야 하는지 구하는 프로그램을 작성하라.<br>
<br>
상원이의 반에는 N명이 있으며, 각 학생들은 1번에서 N번까지의 번호가 붙어 있다.<br>
<br>
여기서 1번 학생이 상원이다.<br>
<br>
<br>
<strong>[입력]</strong><br>
<br>
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.<br>
<br>
각 테스트 케이스의 첫 번째 줄에 두 정수 N, M ( 2 ≤ N ≤ 500, 1 ≤ M ≤ 10<sup>4</sup> ) 이 공백으로 구분되어 주어진다.<br>
<br>
M은 친한 친구 관계의 수 이다.<br>
<br>
다음 M개의 줄의 각 줄에는 두 정수 a, b (1 ≤ a ＜ b ≤ N) 이 주어진다.<br>
<br>
이는 a번 학생과 b번 학생이 서로 친한 친구 관계에 있다는 의미이다.<br>
<br>
<strong>[출력]</strong><br>
<br>
각 테스트 케이스마다 #T를 출력하고 한 칸을 띄운 후, 각 테스트 케이스마다 상원이의 생일 파티 초대장을 받는 친구의 수를 출력한다.<br>
<br>
*상원이의 친구가 없을 수도 있다는 점에 유의해야 한다. 그리고 상원이는 초대장을 받는 사람에 속하지 않는다.<br>
